== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/misinformation-defence-platform.git
cd misinformation-defence-platform
just build-release
----

Output: `{{BUILD_OUTPUT_PATH}}`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t misinformation-defence-platform .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/misinformation-defence-platform/`
| Data files, assets

| `$PREFIX/share/doc/misinformation-defence-platform/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/misinformation-defence-platform/config.toml`

Fallback: `$HOME/.config/misinformation-defence-platform/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update misinformation-defence-platform`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/misinformation-defence-platform-instance1 --config=/etc/misinformation-defence-platform/instance1.toml
just install --prefix=/opt/misinformation-defence-platform-instance2 --config=/etc/misinformation-defence-platform/instance2.toml
----

Each instance has isolated config, data, and logs.
